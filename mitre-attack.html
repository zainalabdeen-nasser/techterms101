What is MITRE ATT&CK?

MITRE ATT&CK is a massive open-source knowledge base that documents hacker and attack group behaviors and tactics based on real-world breach scenarios.

The abbreviation ATT&CK stands for Adversarial Tactics, Techniques, and Common Knowledge.

Why is the MITRE ATT&CK Framework Important?

  • Standardization of Terminology: Enables cybersecurity teams to speak a globally unified descriptive language to express threats.
  • Improving Defense Systems: Helps close gaps and cover blind spots that attackers might exploit.
  • Evaluating Security Tools: Used to test security tools and assess their ability to detect techniques in the matrix.
  • Understanding APT Group Threats: Provides a complete profile for each known hacker group and its specific techniques.
  • Attack Simulation: Assists Red Teams in executing realistic attack scenarios to test defensive readiness.

What is the MITRE ATT&CK Framework in Cybersecurity?

First: Tactics — The Goal / Why?

Represents the attacker's ultimate objective at a specific stage of the breach.

Second: Techniques — The Method / How?

Represents the practical method an attacker uses to execute a tactic and achieve their goal.

Third: Procedures — Execution / With Which Tool?

Represents the specific implementation of a technique observed in a real-world attack.

MITRE ATT&CK Enterprise Tactics (The 14 Tactics)

  • Reconnaissance: Gathering information about the target to plan future operations.
  • Resource Development: Establishing infrastructure, domains, or accounts to support targeting.
  • Initial Access: Gaining an initial foothold within the target network (e.g., via Phishing).
  • Execution: Running malicious code or scripts on the compromised system.
  • Persistence: Maintaining access across system restarts or credential changes.
  • Privilege Escalation: Gaining higher-level permissions (e.g., Administrator or Root).
  • Defense Evasion: Avoiding detection by security controls, antivirus, or logging systems.
  • Credential Access: Stealing account names, hashes, and passwords.
  • Discovery: Exploring the internal environment and network structure.
  • Lateral Movement: Moving through the network to compromise other high-value systems.
  • Collection: Gathering sensitive data of interest prior to exfiltration.
  • Command and Control (C2): Communicating with compromised systems from an external server.
  • Exfiltration: Stealing and transferring sensitive data out of the target network.
  • Impact: Disrupting availability, encrypting files (Ransomware), or destroying data.

Techniques and Sub-techniques (The How)

Each tactic in the MITRE ATT&CK framework consists of multiple Techniques and Sub-techniques.

Tactic: Privilege Escalation (Gaining higher permissions)

Technique: Process Injection (Injecting code into legitimate processes)

Sub-technique: Process Hollowing (Replacing process code with malicious payloads)

Procedures (The Specific Execution)

Procedures are the most detailed level of MITRE ATT&CK. They describe how a specific hacker group implemented a technique in a real-world attack.

If the Technique is what method was used, the Procedure is how it was specifically carried out.
